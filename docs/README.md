# quiz-ui Business Documentation

These files are the frontend-facing business/context layer derived from the backend MVP documentation.

Recommended reading order for an AI coding agent:

1. `PROJECT.md`
2. `BUSINESS_RULES.md`
3. `DATA_MODEL.md`
4. `API.md`
5. `UI_WORKFLOWS.md`

Backend implementation details were intentionally excluded unless they affect frontend behavior.

These documents are not a replacement for the existing `AGENTS.md`, `ARCHITECTURE.md`, `CODING_RULES.md`, and `TESTING.md`. They complement those files by supplying product/business context.
